# Data dictionary

UTF-8 tab-separated files, one header row. Blank means no value recorded at the audit boundary, never zero or confirmed absence. Explicit `UNRESOLVED`, `UNKNOWN`, `NONE_PUBLIC` and other sentinels remain strings with their documented meanings. Empty evidence fields are interpreted alongside node status. `NONE_PUBLIC` is an explicit non-public source assessment; `UNRESOLVED` does not establish absence. Identifiers are strings. Pipe-delimited fields encode multiple values, not additional rows. All allowed protocol status values are listed below, including values unobserved in this release. Other closed vocabularies list the observed v1.0.0 values; identifiers/text remain open.

## Companion tables

The locked claim table preserves human claim wording and anchors. Cohort-design rows aggregate paper IDs and design tags; donor counts are blank when unverified, and paired case/control counts can refer to the same people. Node-closure counts are marginal; nested-attrition counts are sequential intersections. First-unclosed rows are rule-derived descriptions and do not alter classes. Bootstrap columns report percent units, 10,000 replicates and seed 20261008. Blank zero-event interval limits mean NOT_INFORMATIVE_FOR_ZERO_EVENT, not missing estimates to impute. QC outputs are consistency checks, not independent reviewer ratings. Source citation rows link paper identifiers, verified citation metadata and accession strings.
